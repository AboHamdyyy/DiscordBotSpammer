# 🤖 Discord Spam Bot (Node.js & Discord.js v14)

A modern Discord bot built with **Node.js** and **Discord.js v14**, supporting Slash Commands and interactive buttons for smooth message spamming without timeout errors.

---

## ✨ Features
* ⚡ **Instant Response:** Uses `deferUpdate` to prevent "The application did not respond" errors.
* 🔘 **Interactive Buttons:** Full control over sending and repeating spam operations via custom buttons.
* 🚀 **One-Click Launcher:** Includes a smart startup script that checks dependencies and launches the bot automatically.

---

## ⚙️ Prerequisites
Make sure you have installed:
* [Node.js](https://nodejs.org/) (v18 or newer).

---

## 📥 Installation & Setup

1. **Clone or Download:**
   Download the project repository as a ZIP or clone it using Git.

2. **Configure Token:**
   * Create or open `config.json`.
   * Paste your Discord Bot Token inside it like this:
     ```json
     {
       "TOKEN": "YOUR_BOT_TOKEN_HERE"
     }
     ```

3. **Run:**
   * Simply double-click the **`start.bat`** file, and it will handle the dependencies installation and boot up the bot instantly!

---

## 📌 Commands
* `/spam [message]` : Sends the spam message with interactive buttons in the channel.
